## Como usar

1. Escolha a imagem.
2. Renomeie exatamente conforme a lista acima.
3. Faça upload para esta pasta `assets/`.
4. O site passa a usar a imagem automaticamente.

Enquanto um arquivo ainda não existir, o layout mantém o placeholder visual atual.

## Recomendações práticas

- Preferir JPG otimizado para fotografias.
- Evitar arquivos excessivamente grandes.
- Hero: enquadramento vertical.
- Portfólio: fotos com o assunto centralizado o suficiente para aceitar `object-fit: cover`.
- Before/After: usar o mesmo enquadramento e proporção nos dois arquivos de cada par.
- Atendimento em domicílio: imagem horizontal ou vertical ampla que suporte corte responsivo.

Não trocar os nomes no HTML. A convenção desta pasta é a fonte de verdade para os assets fotográficos da V1.
