# Leo Thaylor — Barber

V1 do site pessoal de **Leo Thaylor**, construída em HTML, CSS e JavaScript puros para publicação simples e rápida via GitHub Pages.

## Estado atual

Branch de desenvolvimento: `v1-site`

Estrutura implementada:

- Hero pessoal
- Trabalhos / portfólio
- Before & After interativo
- Relatos de clientes
- Atendimento em domicílio
- Localização / contato
- CTA final

## Pendências editoriais

A V1 usa placeholders intencionais enquanto os assets definitivos não são selecionados.

Ainda precisam ser definidos:

- foto principal;
- fotos reais de trabalhos;
- pares reais de Before/After;
- relatos reais de clientes;
- número de WhatsApp;
- endereço final;
- mapa definitivo.

Nenhum depoimento fictício foi inserido.

## Stack

- HTML
- CSS
- JavaScript
- sem framework
- sem build step
- sem dependências externas obrigatórias
